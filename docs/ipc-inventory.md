# IPC inventory

Generated by `scripts/ipc-inventory.mjs` from `shared/ipc/channels.ts`, `shared/ipc/contracts.ts`,
`electron/preload.ts` and `electron/ipc/`. Regenerate it after a channel changes:

```sh
node scripts/ipc-inventory.mjs > docs/ipc-inventory.md
```

The script fails if a channel has no classification, no preload entry or no handler. The classification
(risk, port) is written in the script, not inferred, so a change of risk is a reviewed change.

## Port order

One cut at a time. Each cut adds the ACL in the Tauri manifest, a capability only for the `main` window,
input and output validation, the paged form with a limit from 1 to 500 and `has_more` for every list, ACL
tests, service tests, a TypeScript and Rust differential, and a browser mock. No command returns a secret.

1. **P3, first cut.** The four commands that already exist: `settings_get`, `workspaces_list`, `conversations_list`.
   `settings_set` belongs to P4. The two lists need the paged form first.
2. **P3, next cuts.** Reads with no write and no process: `conversations.page`, `conversations.messagePage`,
   `validation.list`, `validation.page`, `validation.latest`, `semanticIndex.status`, `semanticIndex.summary`,
   `semanticIndex.search`, `projectIndex.status`, `projectIndex.summary`, `changeControl.get`, `changeControl.changes`,
   `changeControl.hunks`, `models.list`, `models.bindings`, `brain.page`, `brain.history`, `artifacts.list`,
   `artifacts.page`, `suggestions.list`, `suggestions.page`, `ai.rollbackStatus`, `engineeringIntelligence.report`.
   The rest of the P3 rows (project index files, symbols, imports, exports, stack, exclusions; change diffs;
   `providers.list`; `recovery.list`; `evidence.list`) follow after their bounds are set.
3. **P4, database writes.** Ported, except `changeControl.editHunk`, which is blocked and marked beta 2: it enters with
   capture, the change diff, the checkpoint reader, the hunks and the accept and reject decisions. Each delete has its own commit tagged `[review]`. Each write
   tests that a failed write rolls back and that unknown fields are rejected.
4. **P5, observability.** `diagnostics.copy`, `diagnostics.export`, `diagnostics.rendererError`, `diagnostics.rendererStats`,
   and the operation observer for the commands already ported.
5. **Not in the current queue.** Every row marked `later`, `P8`, or `stop`. Those need their own decision, and
   the `stop` rows are stop conditions of the plan (vault and secrets, provider network, updater, signing).
